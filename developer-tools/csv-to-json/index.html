CSV to JSON Converter

Paste CSV — or copy cells straight from Excel or Google Sheets — and get clean JSON as you type: an array of objects, arrays, an object keyed by ID, or JSON Lines.

Runs in your browser Free · no sign-up Works on any device

At a glance

  • Turns each CSV row into a JSON object, using the first row as keys (or column1, column2… when there’s no header).
  • Detects the delimiter automatically — comma, semicolon, tab or pipe — so cells copied from Excel or Google Sheets can be pasted directly.
  • Converts numbers, true/false and empty cells into proper JSON values, while phone numbers, PIN codes with leading zeros and long IDs stay text.
  • Columns named like address.city become nested objects.
  • Four output shapes: array of objects, array of arrays, an object keyed by the first column, or JSON Lines — with 2 or 4 spaces, tabs or minified.
  • Follows RFC 4180: quoted fields, commas and line breaks inside quotes, and doubled quotes all work. Runs in your browser; data is never uploaded.

How values are converted

With Convert numbers & booleans on, 42 and 3.14 become numbers, true and false become booleans, and empty cells become null. Values that only look like numbers stay text: anything with a leading zero (phone numbers, PIN codes like 012345, employee IDs like 007) and anything longer than 15 digits (card and account numbers), because JSON numbers would lose those digits.

Switch the option off to keep every value as text exactly as it appears in the CSV.

FAQ

Frequently asked questions

Can I convert an Excel file to JSON?

Yes. Open the sheet, select the cells (including the header row), copy, and paste them here. To use a file instead, save it from Excel as CSV UTF-8 and open that.

Why are some numbers kept as text?

Numbers with leading zeros or more than 15 digits would change if stored as JSON numbers, so they stay text. Turn off “Convert numbers & booleans” to keep everything as text.

What if my CSV uses semicolons?

The delimiter is detected automatically — commas, semicolons (common in Europe), tabs and pipes all work. You can also pick one yourself.

Is my data uploaded?

No. The conversion runs entirely in your browser; your file never leaves your device.

How do I get nested JSON?

Name the columns with dots, like address.city and address.pin, and keep “Nest dotted columns” on. They become {"address": {"city": …, "pin": …}}.

Can I convert JSON back to CSV?

Yes — switch to JSON → CSV, or use the JSON to CSV Converter, which also shows the result as a table.
