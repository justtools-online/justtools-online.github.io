Compare PDFs

Check two versions of a contract, report or form side by side — every added and removed word highlighted, and visual differences on each page. Runs in your browser; nothing is uploaded.

Runs in your browser Free · no sign-up Works on any device

At a glance

  • Text changes compares the two PDFs word by word: added words are green, removed words are red and struck through.
  • A summary shows the number of changes, words added and removed, how much text is unchanged and which pages changed.
  • Show only changes folds unchanged text away, and you can jump from one change to the next.
  • Visual compares pages pixel by pixel to catch changes in layout, images, stamps, signatures and scanned pages, in Side by side or Overlay view.
  • Every page pair is checked quickly so pages that look different are marked; pages can be paired by hand when one was added or removed.
  • Save the text comparison as a self-contained HTML report to share or keep.
  • Runs entirely in your browser with PDF.js — neither file is uploaded.

Step by step

How to compare two PDF files

  1. 1

    Add both PDFs

    Drop the Original in the first box and the Changed version in the second — or drop both at once.

  2. 2

    Read the text changes

    Green words were added and red ones removed. Use the arrows to go from one change to the next.

  3. 3

    Check the pages

    Open Visual to see the pages side by side or overlaid, with changed areas tinted.

  4. 4

    Save a report

    Click Download report to keep the highlighted text differences as an HTML file.

Good to know

The text comparison looks at words, not fonts or colours, so a change only to bold, size or colour shows up in the Visual view instead.

If a page was inserted, later pages in the Visual view are paired with the wrong page. Choose the matching pages from the Original and Changed lists to line them up again; the text comparison isn’t affected.

Need to fix the order of pages before comparing? Use the PDF Page Organizer.

FAQ

Frequently asked questions

How do I compare two PDF files for differences?

Add the original and the changed PDF here. The text differences appear straight away — green for added, red for removed — and the Visual tab shows what changed on each page.

Can it compare scanned PDFs?

Yes, with the Visual comparison, which compares the pages as images. The word-by-word comparison needs PDFs with selectable text.

Does it work with Hindi and other languages?

Yes, as long as the PDF has selectable text. Words are compared in any language; some older PDFs with Hindi text store it in a way that can’t be read back, and then the Visual view works best.

Can I compare PDFs with a different number of pages?

Yes. The text comparison follows the words across pages, and in the Visual view you can pair any page of the original with any page of the changed PDF.

Are my files uploaded?

No. Both PDFs are read and compared in your browser, so confidential documents never leave your device.

Is there a file size or page limit?

No fixed limit. Very large PDFs depend on your device’s memory; documents of a few hundred pages work on most computers.
